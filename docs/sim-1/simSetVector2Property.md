# sim.setVector2Property

Sets a vector2 property (double[2])

## Synopsis

```lua
sim.setVector2Property(int target, string propertyName, float[2] propertyState, map options = {})
```

```python
sim.setVector2Property(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
