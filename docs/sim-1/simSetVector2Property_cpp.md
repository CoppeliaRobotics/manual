# simSetVector2Property

Sets a vector2 property (double[2])

## Synopsis

```cpp
int simSetVector2Property(long long target, const char* propertyName, const double* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
