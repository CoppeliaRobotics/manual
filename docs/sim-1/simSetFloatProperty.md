# sim.setFloatProperty

Sets a float property (double)

## Synopsis

```lua
sim.setFloatProperty(int target, string propertyName, float propertyState, map options = {})
```

```python
sim.setFloatProperty(int target, string propertyName, float propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
