# sim.setIntProperty

Sets an int32 property

## Synopsis

```lua
sim.setIntProperty(int target, string propertyName, int propertyState, map options = {})
```

```python
sim.setIntProperty(int target, string propertyName, int propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
