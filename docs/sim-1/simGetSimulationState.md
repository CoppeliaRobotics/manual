# sim.getSimulationState

Retrieves current [simulation state](../apiConstants-1.md#simulationStatus)

## Synopsis

```lua
int simulationState = sim.getSimulationState()
```

```python
int simulationState = sim.getSimulationState()
```

## Parameters

No parameters.

## Return values

- **simulationState**: current [state of the simulation](../apiConstants-1.md#simulationStatus)
