# sim.resetGraph

Resets a graph object (i.e. clears all its data streams)

## Synopsis

```lua
sim.resetGraph(int graphHandle)
```

```python
sim.resetGraph(int graphHandle)
```

## Parameters

- **graphHandle**: handle of the graph object

## Return values

No return values.
