# sim.setBoolProperty

Sets a boolean property

## Synopsis

```lua
sim.setBoolProperty(int target, string propertyName, bool propertyState, map options = {})
```

```python
sim.setBoolProperty(int target, string propertyName, bool propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
