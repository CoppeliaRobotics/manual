# sim.textEditorShow

Shows or hides a text edition window previously opened with [sim.textEditorOpen](simTextEditorOpen.md)

## Synopsis

```lua
sim.textEditorShow(int handle, bool showState)
```

```python
sim.textEditorShow(int handle, bool showState)
```

## Parameters

- **handle**: handle of the text editor window
- **showState**: desired show state of the text editor window

## Return values

No return values.
