# simRemoveDrawingObject

Removes a previously added drawing object

## Synopsis

```cpp
int simRemoveDrawingObject(int objectHandle)
```

## Parameters

- **objectHandle**: handle of a previously added drawing object

## Return values

- -1 if operation was not successful
