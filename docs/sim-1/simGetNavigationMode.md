# sim.getNavigationMode

Retrieves the navigation and selection mode for the mouse

## Synopsis

```lua
int navigationMode = sim.getNavigationMode()
```

```python
int navigationMode = sim.getNavigationMode()
```

## Parameters

No parameters.

## Return values

- **navigationMode**: [navigation mode](../apiConstants-1.md#navigationModes)
