# sim.setStringProperty

Sets a string property (text)

## Synopsis

```lua
sim.setStringProperty(int target, string propertyName, string propertyState, map options = {})
```

```python
sim.setStringProperty(int target, string propertyName, string propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
