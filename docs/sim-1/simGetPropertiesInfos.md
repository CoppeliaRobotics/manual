# sim.getPropertiesInfos

Convenience function to fetches all properties infos of a specific target item

## Synopsis

```lua
map propertiesInfo = sim.getPropertiesInfos(int target, map options = {})
```

```python
dict propertiesInfo = sim.getPropertiesInfos(int target, dict options = {})
```

## Parameters

- **target**: target item
- **options**: an optional map

## Return values

- **propertiesInfo**: properties infos
