# simSetColorProperty

Sets a color property (float[3])

## Synopsis

```cpp
int simSetColorProperty(long long target, const char* propertyName, const float* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
