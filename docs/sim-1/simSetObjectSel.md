# sim.setObjectSel

Sets the object selection state

## Synopsis

```lua
sim.setObjectSel(int[] objectHandles)
```

```python
sim.setObjectSel(list objectHandles)
```

## Parameters

- **objectHandles**: handles of objects to be selected

## Return values

No return values.
