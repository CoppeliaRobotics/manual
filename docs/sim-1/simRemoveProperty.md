# sim.removeProperty

Removes a removable property

## Synopsis

```lua
sim.removeProperty(int target, string propertyName, map options = {})
```

```python
sim.removeProperty(int target, string propertyName, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
