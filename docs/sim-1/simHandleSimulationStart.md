# sim.handleSimulationStart

Initializes various functionality (e.g. camera tracking during simulation, object velocity calculation, etc.). Should only be called from the [main script](../mainScript.md), as the first instruction in the *initialization* section

## Synopsis

```lua
sim.handleSimulationStart()
```

```python
sim.handleSimulationStart()
```

## Parameters

No parameters.

## Return values

No return values.
