# sim.getMatrixInverse

Inverts a transformation matrix

## Synopsis

```lua
float[12] matrix = sim.getMatrixInverse(float[12] matrix)
```

```python
list matrix = sim.getMatrixInverse(list matrix)
```

## Parameters

- **matrix**: the input matrix

## Return values

- **matrix**: the output matrix
