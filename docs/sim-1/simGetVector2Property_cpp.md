# simGetVector2Property

Fetches a vector2 property (double[2])

## Synopsis

```cpp
int simGetVector2Property(long long target, const char* propertyName, double* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
