# sim.getPropertyName

Fetches the name of a property, based on an index

## Synopsis

```lua
string propertyName = sim.getPropertyName(int target, int index, map options = {})
```

```python
string propertyName = sim.getPropertyName(int target, int index, dict options = {})
```

## Parameters

- **target**: target item
- **index**: property index
- **options**: an optional map. Set options.prefix to perform an initial filtering based on a prefix

## Return values

- **propertyName**: property name
