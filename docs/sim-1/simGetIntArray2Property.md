# sim.getIntArray2Property

Fetches an int[2] property

## Synopsis

```lua
int[2] propertyState = sim.getIntArray2Property(int target, string propertyName, map options = {})
```

```python
list propertyState = sim.getIntArray2Property(int target, string propertyName, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

- **propertyState**: property value
