# simSaveScene

Saves a scene. Any existing file with same name will be overwritten

## Synopsis

```cpp
int simSaveScene(const char* filename)
```

## Parameters

- **filename**: scene filename. The filename extension is required

## Return values

- -1 if operation was not successful
