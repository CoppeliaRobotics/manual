# sim.ruckigRemove

Removes an object previously created via [sim.ruckigPos](simRuckigPos.md) or [sim.ruckigVel](simRuckigVel.md).

## Synopsis

```lua
sim.ruckigRemove(int handle)
```

```python
sim.ruckigRemove(int handle)
```

## Parameters

- **handle**: handle of the object created via [sim.ruckigPos](simRuckigPos.md) or [sim.ruckigVel](simRuckigVel.md).

## Return values

No return values.
