# sim.systemSemaphore

Acquires or releases a system-wide semaphore, i.e. across several CoppeliaSim instances

## Synopsis

```lua
sim.systemSemaphore(string key, bool acquire)
```

```python
sim.systemSemaphore(string key, bool acquire)
```

## Parameters

- **key**: the key
- **acquire**: whether the semaphore should be acquired or released

## Return values

No return values.
