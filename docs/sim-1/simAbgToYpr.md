# sim.abgToYpr

Converts CoppeliaSim's alpha-beta-gamma angles to Yaw-Pitch-Roll angles

## Synopsis

```lua
float[3] anglesOut = sim.abgToYpr(float[3] anglesIn)
```

```python
list anglesOut = sim.abgToYpr(list anglesIn)
```

## Parameters

- **anglesIn**: 3 angles: alpha, beta and gamma

## Return values

- **anglesOut**: 3 angles: yaw, pitch and roll
