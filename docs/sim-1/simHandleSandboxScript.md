# sim.handleSandboxScript

Lua only. Calls a specific function in the [sandbox](../sandboxScript.md). sim.handleSandboxScript should only be called from the [main script](../mainScript.md)

## Synopsis

```lua
sim.handleSandboxScript(int callType)
```

## Parameters

- **callType**: system call type (e.g. *sysCall_actuation*)

## Return values

No return values.
