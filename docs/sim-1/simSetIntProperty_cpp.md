# simSetIntProperty

Sets an int32 property

## Synopsis

```cpp
int simSetIntProperty(long long target, const char* propertyName, int propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value

## Return values

- 1 in case of success
