# simSetStringProperty

Sets a string property (text)

## Synopsis

```cpp
int simSetStringProperty(long long target, const char* propertyName, const char* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
