# sim.getQuaternionInverse

Inverts a quaternion

## Synopsis

```lua
float[4] quat = sim.getQuaternionInverse(float[4] quat)
```

```python
list quat = sim.getQuaternionInverse(list quat)
```

## Parameters

- **quat**: the input quaternion

## Return values

- **quat**: the output quaternion
