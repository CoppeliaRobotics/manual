# simRuckigRemove

Removes an object previously created via [sim.ruckigPos](simRuckigPos.md) or [sim.ruckigVel](simRuckigVel.md).

## Synopsis

```cpp
int simRuckigRemove(int handle)
```

## Parameters

- **handle**: handle of the object created via [simRuckigPos](simRuckigPos.md) or [simRuckigVel](simRuckigVel.md).

## Return values

- 1 in case of success
