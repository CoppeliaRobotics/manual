# sim.setNavigationMode

Sets the navigation and selection mode for the mouse

## Synopsis

```lua
sim.setNavigationMode(int navigationMode)
```

```python
sim.setNavigationMode(int navigationMode)
```

## Parameters

- **navigationMode**: [mouse navigation mode](../apiConstants-1.md#navigationModes)

## Return values

No return values.
