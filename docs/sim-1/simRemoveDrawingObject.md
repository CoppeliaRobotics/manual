# sim.removeDrawingObject

Removes a previously added drawing object

## Synopsis

```lua
sim.removeDrawingObject(int objectHandle)
```

```python
sim.removeDrawingObject(int objectHandle)
```

## Parameters

- **objectHandle**: handle of a previously added drawing object

## Return values

No return values.
