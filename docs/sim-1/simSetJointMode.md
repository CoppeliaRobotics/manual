# sim.setJointMode

Sets the operation mode of a joint

## Synopsis

```lua
sim.setJointMode(int jointHandle, int jointMode)
```

```python
sim.setJointMode(int jointHandle, int jointMode)
```

## Parameters

- **jointHandle**: handle of the joint object
- **jointMode**: [joint mode](../apiConstants-1.md#jointModes) value

## Return values

No return values.
