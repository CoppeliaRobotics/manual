# sim.setProperty

Convenience function to set a property

## Synopsis

```lua
sim.setProperty(int target, string propertyName, any propertyState, int propertyType = nil)
```

```python
sim.setProperty(int target, string propertyName, any propertyState, int propertyType = None)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **propertyType**: an optional property type

## Return values

No return values.
