# simGetStackSize

Returns the size of the stack

## Synopsis

```cpp
int simGetStackSize(int stackHandle)
```

## Parameters

- **stackHandle**: a stack handle obtained with [simCreateStack](simCreateStack_cpp.md).

## Return values

- -1 in case of an error, otherwise the size of the stack.
