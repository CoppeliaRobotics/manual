# sim.getPoseInverse

Inverts a pose

## Synopsis

```lua
float[7] pose = sim.getPoseInverse(float[7] pose)
```

```python
list pose = sim.getPoseInverse(list pose)
```

## Parameters

- **pose**: the input pose

## Return values

- **pose**: the output pose
