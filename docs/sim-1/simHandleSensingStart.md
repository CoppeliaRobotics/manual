# sim.handleSensingStart

Handles various functionality (e.g. camera tracking during simulation, object velocity calculation, etc.). Should only be called from the [main script](../mainScript.md), as the first instruction in the *sensing* section

## Synopsis

```lua
sim.handleSensingStart()
```

```python
sim.handleSensingStart()
```

## Parameters

No parameters.

## Return values

No return values.
