# simPushTableOntoStack

Pushes an empty table onto the stack. The table will then be located at the top of the stack

## Synopsis

```cpp
int simPushTableOntoStack(int stackHandle)
```

## Parameters

- **stackHandle**: stack handle obtained with [simCreateStack](simCreateStack_cpp.md).

## Return values

- -1 in case of an error.
