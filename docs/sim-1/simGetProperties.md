# sim.getProperties

Convenience function to fetches all properties of a specific target item

## Synopsis

```lua
map properties = sim.getProperties(int target, map options = {})
```

```python
dict properties = sim.getProperties(int target, dict options = {})
```

## Parameters

- **target**: target item
- **options**: an optional map. Set options.skipLarge = true to skip large data

## Return values

- **properties**: properties
