# sim.acquireLock

Allows to have CoppeliaSim wait for a threaded code section to be executed without interruption. Locking is cumulative

## Synopsis

```lua
sim.acquireLock()
```

```python
sim.acquireLock()
```

## Parameters

No parameters.

## Return values

No return values.
