# sim.cancelScheduledExecution

Cancels a scheduled execution of a function

## Synopsis

```lua
bool canceled = sim.cancelScheduledExecution(int id)
```

```python
bool canceled = sim.cancelScheduledExecution(int id)
```

## Parameters

- **id**: id of the scheduled execution function

## Return values

- **canceled**: cancelation status
