# sim.getObjectSel

Retrieves the handles of selected objects

## Synopsis

```lua
int[] selectedObjects = sim.getObjectSel()
```

```python
list selectedObjects = sim.getObjectSel()
```

## Parameters

No parameters.

## Return values

- **selectedObjects**: the handles of selected objects
