# sim.setColorProperty

Sets a color property (float[3])

## Synopsis

```lua
sim.setColorProperty(int target, string propertyName, float[3] propertyState, map options = {})
```

```python
sim.setColorProperty(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
