# sim.setIntArrayProperty

Sets an int array property (int[])

## Synopsis

```lua
sim.setIntArrayProperty(int target, string propertyName, int[] propertyState, map options = {})
```

```python
sim.setIntArrayProperty(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
