# sim.setFloatArrayProperty

Sets a float array property (double[])

## Synopsis

```lua
sim.setFloatArrayProperty(int target, string propertyName, float[] propertyState, map options = {})
```

```python
sim.setFloatArrayProperty(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
