# simGetBoolProperty

Fetches a boolean property

## Synopsis

```cpp
int simGetBoolProperty(long long target, const char* propertyName, int* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value

## Return values

- 1 in case of success
