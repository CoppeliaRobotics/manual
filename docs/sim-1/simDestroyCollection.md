# sim.destroyCollection

Removes a [collection](../collections.md)

## Synopsis

```lua
sim.destroyCollection(int collectionHandle)
```

```python
sim.destroyCollection(int collectionHandle)
```

## Parameters

- **collectionHandle**: handle of the collection to remove

## Return values

No return values.
