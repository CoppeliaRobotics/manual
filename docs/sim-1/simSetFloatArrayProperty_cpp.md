# simSetFloatArrayProperty

Sets a float array property (double[])

## Synopsis

```cpp
int simSetFloatArrayProperty(long long target, const char* propertyName
                             const double* propertyPointer, int propertyLength)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyPointer**: pointer to property value
- **propertyLength**: property length

## Return values

- 1 in case of success
