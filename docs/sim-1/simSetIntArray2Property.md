# sim.setIntArray2Property

Sets an int[2] property

## Synopsis

```lua
sim.setIntArray2Property(int target, string propertyName, int[2] propertyState, map options = {})
```

```python
sim.setIntArray2Property(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
