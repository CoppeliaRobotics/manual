# sim.destroyGraphCurve

Destroys a graph stream or curve

## Synopsis

```lua
sim.destroyGraphCurve(int graphHandle, int curveId)
```

```python
sim.destroyGraphCurve(int graphHandle, int curveId)
```

## Parameters

- **graphHandle**: handle of the graph
- **curveId**: id of the stream or curve, -1 to remove all streams/curves

## Return values

No return values.
