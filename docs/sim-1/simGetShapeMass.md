# sim.getShapeMass

Retrieves the mass of a shape

## Synopsis

```lua
float mass = sim.getShapeMass(int shapeHandle)
```

```python
float mass = sim.getShapeMass(int shapeHandle)
```

## Parameters

- **shapeHandle**: handle of the [shape object](../shapes.md)

## Return values

- **mass**: mass of the shape
