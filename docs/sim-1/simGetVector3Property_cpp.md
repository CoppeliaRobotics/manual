# simGetVector3Property

Fetches a vector3 property (double[3])

## Synopsis

```cpp
int simGetVector3Property(long long target, const char* propertyName, double* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
