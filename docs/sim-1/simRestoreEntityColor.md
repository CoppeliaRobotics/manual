# sim.restoreEntityColor

Restores the color of an [entity](../entities.md), previously modified with [sim.changeEntityColor](simChangeEntityColor.md)

## Synopsis

```lua
sim.restoreEntityColor(map[] originalColorData)
```

```python
sim.restoreEntityColor(list originalColorData)
```

## Parameters

- **originalColorData**: the data returned from a call to [sim.changeEntityColor](simChangeEntityColor.md)

## Return values

No return values.
