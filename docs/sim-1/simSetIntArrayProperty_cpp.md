# simSetIntArrayProperty

Sets an int array property (int[])

## Synopsis

```cpp
int simSetIntArrayProperty(long long target, const char* propertyName, const int* propertyPointer
                           int propertyLength)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyPointer**: pointer to property value
- **propertyLength**: property length

## Return values

- 1 in case of success
