# sim.setProperties

Convenience function to set several properties at once

## Synopsis

```lua
sim.setProperties(int target, map properties)
```

```python
sim.setProperties(int target, dict properties)
```

## Parameters

- **target**: target item
- **properties**: a map where keys are propertyNames and values are propertyStates

## Return values

No return values.
