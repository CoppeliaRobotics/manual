# simGetIntArray2Property

Fetches an int[2] property

## Synopsis

```cpp
int simGetIntArray2Property(long long target, const char* propertyName, int* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: pointer to property value

## Return values

- 1 in case of success
