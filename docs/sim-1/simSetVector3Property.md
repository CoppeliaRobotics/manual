# sim.setVector3Property

Sets a vector3 property (double[3])

## Synopsis

```lua
sim.setVector3Property(int target, string propertyName, float[3] propertyState, map options = {})
```

```python
sim.setVector3Property(int target, string propertyName, list propertyState, dict options = {})
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value
- **options**: an optional map. Set options.noError to true for silent errors

## Return values

No return values.
