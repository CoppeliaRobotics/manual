# simGetLongProperty

Fetches an int64 property

## Synopsis

```cpp
int simGetLongProperty(long long target, const char* propertyName, long long* propertyState)
```

## Parameters

- **target**: target item
- **propertyName**: property name
- **propertyState**: property value

## Return values

- 1 in case of success
