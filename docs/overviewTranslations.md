## <a id="English"></a>English

[CoppeliaSim](http://coppeliarobotics.com) is the Swiss army knife among robotics simulators:

- Cross-platform (Windows, MacOSX, Linux)
- [6 programming approaches](writingCode.md#sixMethods) ([embedded scripts](scripts.md), [plugins](plugins.md), [add-ons](addOns.md), [ROS nodes](rosInterfaces.md), or [remote API](remoteApiOverview.md) clients)
- 6 programming languages ([C/C++](apiFunctions.md), [Python](zmqRemoteApiOverview.md), [Java](zmqRemoteApiOverview.md), [Lua](apiFunctions.md), [Matlab](zmqRemoteApiOverview.md), and [Octave](zmqRemoteApiOverview.md))
- More than [1000 methods and properties](apiFunctions.md)
- [5 physics engines](dynamicsModule.md) ([MuJoCo](https://mujoco.org/), [ODE](http://www.ode.org/), [Bullet](http://www.bulletphysics.org/), [Vortex](https://www.cm-labs.com/vortex-studio/), [Newton](http://www.newtondynamics.com))
- Integrated ray-tracer ([POV-Ray](http://www.povray.org/))
- [Full kinematics solver](kinematics.md) (IK and FK for ANY mechanisms)
- [Mesh, OC tree and point cloud interference detection](collisionDetection.md)
- [Mesh, OC tree and point cloud minimum distance calculation](distanceCalculation.md)
- [Path/motion planning](pathAndMotionPlanningModules.md) (holonomic in 2-6 dimensions, non-holonomic for car-like vehicles, and motion planning for kinematic chains)
- [Vision sensors](visionSensors.md) with built-in image processing (fully extendable)
- Realistic [proximity sensors](proximitySensors.md) (minimum distance calculation within a detection volume)
- Built-in [custom user interfaces](customUIPlugin.md)
- Fully integrated [Reflexxes Motion Library](http://www.reflexxes.com), [Ruckig Online Trajectory Generator](https://github.com/pantor/ruckig#readme) and [RRS-1 interface specifications](http://www.realistic-robot-simulation.org/)
- [Data recording and visualization](graphs.md) (time graphs, X/Y graph or 3D curves)
- Integrated [shape edit modes](shapeEditModes.md)
- Dynamic particles for water-/air-jet simulation
- [Model browser](userInterface.md#ModelBrowser) with drag-and-drop functionality (also during simulation)
- Multi-level undo/redo, [movie recorder](aviRecorder.md), simulation of paint dispensing, exhaustive documentation, etc.
