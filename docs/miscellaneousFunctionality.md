# Miscellaneous functionality

Since CoppeliaSim can easily be extended via a [plugin](plugins.md) or an [add-on](addOns.md), the scope of functionality that can be achieved is virtually unlimited. The following plugins also ship with CoppeliaSim:

- [CGAL plugin](simSurfRec/simSurfRec.htm) (surface reconstruction).
- [ICP plugin](simICP/simICP.htm) (point cloud matching).
- [Subprocess plugin](simSubprocess/simSubprocess.htm) (launch and handle subprocesses).
- [Eigen plugin](simEigen/simEigen.htm) (matrix operations).
