Script editor

The script editor allows editing simulation- and customization scripts in CoppeliaSim. It is opened by double-clicking a script in the scene hierarchy.

[Script editor]


When a script was modified, there is no need to explicitly save the changes: closing the script editor, saving the scene or starting a simulation automatically applies the changes to a simulation script. The user can also explicitly restart/reset a given script, for changes to take immediately effect.

An external script editor can also be specified by editing usrset.txt and restarting CoppeliaSim.
