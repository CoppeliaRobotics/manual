Embedded scripts

CoppeliaSim supports, next to sandboxes and add-ons, also embedded scripts: those are scripts that are embedded in a scene (or model), i.e. scripts that are part of the scene and that are saved and loaded together with the rest of the scene (or model). Different types of embedded scripts are supported, each has specific features and application areas:

[Embedded script types]


  • Script objects are instances of the scriptObject type, which in turn derives from the sceneObject type. They wrap an instance of the script type and come in two flavours: simulation scripts and customization scripts
  • The main script is an instance of the script type and represents the simulation loop code that allows a simulation to run. Without main script, a running simulation won't do anything significant

    • Embedded scripts, and all scripts in general, are invoked via callback functions by CoppeliaSim, and follow a specific execution order. They can run threaded or non-threaded.
