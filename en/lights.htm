Lights

A light is an instance of type light, which derives from type sceneObject. It allows to light a scene. Without any light in the scene, objects appear in unshaded colors (in that case objects are only illuminated with an ambient light component that can be set in the environment dialog). Following figure illustrates the effect of lights in a scene:

[Scene illuminated (1) with ambient light only, (2) with a directional light, (3) with a spotlight]


There can be up to eight active lights in a scene. There are three different types of lights:

  • Omnidirectional lights: it illuminates the scene as a point light source.
  • Spotlights: it illuminates the scene only in one specific direction, with a specific light cone angle.
  • Directional lights: it illuminates the scene only in one specific direction and its strength does not fade (its position is not matter).

    • [(1) omnidirectional light, (2) spotlight, (3) directional light]


    A light can be added to the scene with [Add > Light]. Refer also to sim.scene:createObject and light-related methods and properties.
