Data visualization/output

Data can be visualized or output/logged in various ways:

  • Web-browser based front-end
  • Visualizing data in graphs
  • Displaying data in custom user interfaces
  • Augmenting the scene with visual items
  • Logging data to the status bar via the simple print command
  • Logging data to the status bar and/or terminal via sim.app:logInfo, sim.app:logWarn and sim.app:logError
  • Logging data to a file
  • Printing text in a console
  • Text editing

    • The following example illustrates how to display a joint angle in a simple custom user interface:

    #python # using sim-2 import math def sysCall_init(): simUI = require('simUI') self.joint = sim.self:getObject('/Joint') xml = """ <ui title="Example" closeable="false" layout="form"> <label text="joint angle:" /> <label id="1" text="-" /> </ui> """ self.ui = simUI.create(xml) def sysCall_sensing(): v = 180 * self.joint.joint.position / math.pi simUI.setLabelText(self.ui, "1", '{:.3f}'.format(v)) def sysCall_cleanup(): simUI.destroy(self.ui) --lua function sysCall_init() sim = require('sim-2') simUI = require('simUI') joint = sim.self:getObject('/Joint') local xml =[[<ui title="Example" closeable="false" layout="form"> <label text="joint angle:" /> <label id="1" text="-" /> </ui>]] ui = simUI.create(xml) end function sysCall_sensing() local v = 180 * joint.joint.position / math.pi simUI.setLabelText(ui, 1, string.format('%.3f', v)) end function sysCall_cleanup() simUI.destroy(ui) end

    More complex items, such as random meshes can be created on the fly via sim.scene:loadModel, sim.scene:createObject and/or sim.scene:duplicateObjects. To avoid overloading the scene with too many additional objects, make sure to group shapes with sim.scene:groupShapes or sim.scene:mergeShapes. For example:

    --lua function sysCall_init() sim = require('sim-2') local individualShapes = {} for i = 0, 359, 1 do local shape = sim.scene:createObject({type = 'shape', ['color.diffuse'] = Color('red'), cylinder = {radius = 0.0025, length = 0.02}}) local coord = {math.cos(i * math.pi / 180), math.sin(i * math.pi / 180), 0.01} shape.worldPosition = coord individualShapes[i + 1] = shape end -- Merge the shapes: local masterShape = sim.scene:mergeShapes(individualShapes) -- Make it invisible to collision detection, sensors, etc.: masterShape.collidable = false masterShape.measurable = false masterShape.detectable = false end

    Logging data to a file

    The following example illustrates how to log a joint angle to a file:

    #python # using sim-2 import math def sysCall_init(): self.joint = sim.self.getObject('/Joint') self.file = open('jointAngles.txt', 'w+') self.file.write('Joint angles for each simulation step:\n\n') def sysCall_sensing(): v = 180 * self.joint.joint.position / math.pi self.file.write('time: {:.3f} [s]'.format(sim.scene.simulation.time + sim.scene.simulation.timeStep)) self.file.write(', joint angle: {:.1f} [deg]\n'.format(v)) def sysCall_cleanup(): self.file.close() --lua function sysCall_init() sim = require('sim-2') joint = sim.self:getObject('/Joint') file = io.open('jointAngles.txt', 'w+') file:write('Joint angles for each simulation step:\n\n') end function sysCall_sensing() local v = 180 * joint.joint.position / math.pi file:write(string.format('time: %.3f [s]', sim.scene.simulation.time + sim.scene.simulation.timeStep)) file:write(string.format(', joint angle: %.1f [deg]\n', v)) end function sysCall_cleanup() file:close() end

    Printing text in a console

    The following example illustrates how to create an auxiliary console, and print text into it:

    --lua function sysCall_init() sim = require('sim-2') console = sim.app:createObject({type = 'console'}) end function sysCall_sensing() if console:isValid() then console:print('sim. time: ' .. sim.scene.simulation.time .. '\n') end end function sysCall_cleanup() if console:isValid() then console:remove() end end

    Text editing

    The following example illustrates how to edit text in an editor:

    --lua function sysCall_init() sim = require('sim-2') editor = sim.app:createObject({type = 'textEditor'}) end function sysCall_cleanup() if editor:isValid() then print(editor.text) editor:remove() end end
