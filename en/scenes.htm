Scenes

Compared to models, a scene can contain exactly the same type of elements, but additionally also includes the following elements, specific to scenes:

  • The environment
  • The main script
  • Pages and views

    • A scene or scene image content can be seen through a viewable object associated with a view, itself contained in a page. When creating a new scene ([File > New Scene]), the default scene contains the following elements:

  • Several cameras to display the scene (or parts of it).
  • Several lights to illuminate the scene.
  • Several views to display what cameras see. Views are contained in pages.
  • Several pages containing one or several views.
  • The environment holding properties such as ambient light, background color, etc.
  • The floor, made up by shapes grouped in a model.
  • The default main script running code required by every scene. It is in charge of handling sensors, calling simulation and customization scripts, etc.

    • Scenes can be opened with [File > Open Scene...] and saved with [File > Save Scene] or [File > Save Scene as]. Scene files (*.ttt files) also support drag and drop operations between the explorer window and the application window. They can also be double-clicked, in which case they will launch the CoppeliaSim application and be opened. Refer also to sim.app:loadScene, sim.scene:remove.
