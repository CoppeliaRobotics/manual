Kinematics Plugin

The kinematics plugin for CoppeliaSim (simIK.dll or similar) wraps the Coppelia Kinematics Routines. The plugin itself is wrapped in the IK classes, offering methods and properties for IK, IKGroup, IKElement, IKObject and IKJoint objects; they allow to create, handle and solve forward/inverse kinematics tasks via Jacobian for any type of mechanism (redundant/non-redundant, containing nested loops, etc.) fully programmatically.

Kinematics tasks can easily be set up from the scene's content like in following example:

--lua -- set-up: function sysCall_init() sim = require('sim-2') local simIK = require('simIK-2') local simBase = sim.self:getObject('/base') local simTip = sim.self:getObject('/tip') local simTarget = sim.self:getObject('/target') ik = simIK() local ikGroup = ik:createGroup({method = 'dampedLeastSquares', damping = 0.01, maxIterations = 10}) local ikElement = ikGroup:addElementFromScene(simBase, simTip, simTarget, ik.constraint_pose, {precision = {0.0005, 0.005 * math.pi / 180.0}}) end -- IK calculation, and application to the scene: function sysCall_actuation() ik:solve() end

IKGroup:addElementFromScene parses the scene given a base, tip and target object, and generates an appropriate IK element, with the given constraints. IK:solve on the other hand synchronizes the IK world with the sim world, computes IK, then synchronize the sim world back from the IK world.
