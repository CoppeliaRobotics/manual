ZeroMQ remote API, version 2

The ZeroMQ remote API version 2 is one of several ways an application can connect with CoppeliaSim. It allows you to control a simulation (or the simulator itself) from an external application or a remote hardware (e.g. real robot, remote computer), and offers all API properties and methods also available via a CoppeliaSim script in sim-2.

The remote API is interacting with CoppeliaSim via ZeroMQ and its interface plugin to CoppeliaSim, and the ZMQ remote API-2 add-on. All this happens in a hidden fashion to the user. The remote API can let one or several external applications interact with CoppeliaSim in a stepping (i.e. synchronized with each simulation step) or non-stepping way (i.e. the normal operation mode), and even remote control of the simulator is supported (e.g. remotely loading a scene, starting, pausing or stopping a simulation for instance).

See programming/zmqRemoteApi-2 folder or its related repository for examples.


Python client

Install client package:

$ python3 -m pip install coppeliasim-zmqremoteapi-2-client

(the ZeroMQ and CBOR dependencies will be automatically installed with the above command).

The following is a very simple example ZeroMQ remote API-2 client code, which starts then runs a stepping simulation for 3 seconds:

from coppeliasim_zmqremoteapi_2_client import RemoteAPIClient client = RemoteAPIClient() sim = client.require('sim') sim.setStepping(True) sim.startSimulation() while (t := sim.getSimulationTime()) < 3: print(f'Simulation time: {t:.2f} [s]') sim.step() sim.stopSimulation()
