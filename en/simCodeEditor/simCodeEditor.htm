simCodeEditor.close

Description Close a code editor window.
Lua synopsis int[] positionAndSize = simCodeEditor.close(int handle)
Lua parameters
handle (int): handle to the code editor window
Lua return values
positionAndSize (table of int): position and size of the editor window
Python synopsis list positionAndSize = simCodeEditor.close(int handle)

simCodeEditor.getText

Description Get the text of a code editor window.
Lua synopsis string text, int[] positionAndSize = simCodeEditor.getText(int handle)
Lua parameters
handle (int): handle to the code editor window
Lua return values
text (string): current text
positionAndSize (table of int): position and size of the editor window
Python synopsis string text, list positionAndSize = simCodeEditor.getText(int handle)

simCodeEditor.open

Description Open a new code editor window.
Lua synopsis int handle = simCodeEditor.open(string initText, string properties="")
Lua parameters
initText (string): initial text
properties (string, default: ""): properties XML string
Lua return values
handle (int): handle to the code editor window
Python synopsis int handle = simCodeEditor.open(string initText, string properties="")

simCodeEditor.openFile

Description Open a new code editor window editing an external file.
Lua synopsis int handle = simCodeEditor.openFile(string filePath, string properties="")
Lua parameters
filePath (string): path of the external file
properties (string, default: ""): properties XML string
Lua return values
handle (int): handle to the code editor window
Python synopsis int handle = simCodeEditor.openFile(string filePath, string properties="")

simCodeEditor.openModal

Description Open a new code editor window, in "speaicl modal" mode (blocks until dialog closed).
Lua synopsis string text, int[] positionAndSize = simCodeEditor.openModal(string initText, string properties="")
Lua parameters
initText (string): initial text
properties (string, default: ""): properties XML string
Lua return values
text (string): final text
positionAndSize (table of int): position and size of the editor window
Python synopsis string text, list positionAndSize = simCodeEditor.openModal(string initText, string properties="")
