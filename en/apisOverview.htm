CoppeliaSim API framework

Within CoppeliaSim, one can distinguish between two group of functions, methods and properties:

  • the regular API is made available by CoppeliaSim itself, and represents the core functionality:
    • sim-1 (version 1)
    • sim-2 (current version)
  • the other API items are mainly functions made available by specific plugins. Each plugin groups its functionality under a unique namespace, e.g. simOMPL, simUI, etc. The documentation to those functions can be found in the functionality section.

From an external application, there are many different API mechanisms available to communicate and interact with CoppeliaSim.
