Scripts

A script object is an instance of type scriptObject, which derives from type sceneObject. A script object is a scene object that wraps a (naked) script (that holds all scripting functionality). It has no role as a 3D object in a scene, but handles specific parts of a model via code. Following figure shows a script object:

[Script object (most of the time hidden)]


Script objects come in two flavors and wrap two types of scripts:

  • simulation scripts: they hold code that handles a particular function in a simulation, and run only when simulation is running.
  • customization scripts: they hold code that handles a particular customization aspect in a scene or model, and run also when simulation is not running.

    • A double-click on a script in the scene hierarchy opens the script dialog and the script editor.

    Script objects can be added to the scene with [Add > Script object]. Refer also to sim.scene:createObject, scriptObject-related methods and properties, the scriptObject.script property and script-related methods and properties.
