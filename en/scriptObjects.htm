Script objects

A script object is an instance of the scriptObject type, which in turn derives from the sceneObject type. It wraps an instance of the script type (that holds all scripting functionality). It has no direct role as a scene object in a scene, except for handling specific parts of a model via code. Following figure shows a script object:

[Script object (most of the time hidden)]


Script objects come in two flavors and wrap two types of scripts:

  • simulation scripts hold code that handles a particular function in a simulation. They run only when simulation is running.
  • customization scripts hold code that handles a particular customization aspect in a scene or model. They run as soon as the containing scene or model was loaded.

    • A double-click on a script object in the scene hierarchy opens the script dialog and the script editor.

    Script objects can be added to the scene with [Add > Script object]. Refer also to sim.scene:createObject, scriptObject.script, scriptObject-related methods and properties, and script-related methods and properties.
